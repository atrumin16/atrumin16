## Core Engineering Competencies

- **Edge Computing & Serverless:** Cloudflare Workers, Pages Functions, D1 SQL, Workers KV, Edge Cache API, HTTP/3, and custom routing rules.
- **Cloud Infrastructure & Networking:** DNS-over-HTTPS (DoH), WAF rules, reverse proxies, SSL/TLS termination, Proxmox VE virtualization, and Fly.io deployments.
- **Security & Zero-Trust:** Strict Content-Security-Policy (CSP), IAM least privilege, pre-commit entropy analysis, and RFC 7807 problem details error handling.
- **Systems Automation & CI/CD:** GitHub Actions workflows, PowerShell scripting, Bash tooling, and automated deployment pipelines.
- **Software Development:** TypeScript, Node.js, Python, modern Web APIs, and REST/GraphQL interface design.
